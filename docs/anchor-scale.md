# v0.6.0：缩放与接触点锚定

在cinematic的layer内新增可选字段：

```json
{"scale":[1,1.06],"anchor":[0.35,0.97],"rotation":0,"bob":0}
```

示例数值只表示语法，不是当前列车已经校准过的接触点。必须在透明列车实际Alpha包围框上找到车轮接触位置再设置。

scale为起止缩放倍数，范围0.25..2，默认[1,1]，在该幕时长内线性插值。width仍定义缩放前主体相对于画布的宽度。anchor为裁去透明边缘后的主体内部归一化坐标，默认[0.5,0.5]。path此时表示锚点在输出画面上的路径，旧工程使用默认中心锚点保持原语义。

渲染使用整段最大缩放对应的固定透明画布，避免后续放大裁切主体。画布对角线计算包含转动范围的保护余量，边长上限4096像素，超出则拒绝并要求减小width或scale。缩放与转动后的锚点偏移会从overlay位置扣除，使接触点跟随path。

列车初次验证应冻结背景相机。现有图层为屏幕坐标，不能在背景相机明显运动时仍假设一个固定屏幕点自动跟着轨道。若要组合大幅背景运镜，需另做世界到相机坐标映射或整组共同变换。

这提供有限视角下的2.5D运动，不提供任意三维透视、车轮物理或自动轨道识别。新字段经标准layers数组scene patch写入，原有哈希、局部缓存和QA路径继续生效。

除合成素材测试外，现已使用用户提供的无列车背景和透明列车完成4秒试片，参数及结果见examples/train-validation。之后接回examples/weightless-summer-layered的30秒整片，技术QA通过。列车仅作短距离2.5D运动，未验证车轮转动、受电弓接触物理或长距离透视变化。
