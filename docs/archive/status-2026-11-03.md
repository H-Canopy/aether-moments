# v0.3.0 本轮交付

已实现照片 still/push/pull 运动、本地单音轨、音量编辑、短音轨补静音与长音轨裁切、淡入淡出。声音修改保留画面缓存；镜头修改保留未改幕缓存。新音轨素材、音量或照片运动均记录在可编辑工程和修改历史中。

验证：Node 自动测试 17/17 通过；离线分镜页面在 Chromium 实测字幕、时长、运动选择与下载，其他幕保持不变；非法时长被拦截，手机布局无横向溢出。公开照片案例 13 秒、720×1280、24fps，十项自动 QA 检查通过。人工已查看关键帧；未进行主观听感验收。

音轨是程序生成的三音测试和弦，不是专业配乐作品。照片与事实沿用有来源记录的 Apollo 8 公开资料案例，非真实个人记忆验收。照片未增加生成式内容，也未引入第三方 Skill 源码。

本轮源码及测试在 Windows 本机完成，不将它描述为在 CodeArts 上完成的新功能。原 CodeArts 回传记录作为历史证据保留。正式验收仍缺新版本的平台回归、真实个人案例、完整赛规与市场提交。

发布包另附 release-manifest.json，逐文件记录 SHA-256，打包后对压缩包内文件重新验证，避免此前清单与产物混版的问题。旧阶段记录保留日期，不作为当前能力清单；以 SKILL.md 与 media-v030.md 为准。
