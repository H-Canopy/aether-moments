# 地出：档案影像视觉试作

目标：让观众先感受照片，再理解这是一张有来源、可以继续编辑的记忆影像。承认这是公开史料演示，不模拟私人回忆，也不把历史画面误称 AI 生成。

形式：1280×720 横屏，22 秒，无旁白。深黑、偏暖白字与蓝灰来源标注，来自照片本身的黑色空间和地球色彩。序列为日期开场 → Bill Anders 与照片 → 地平线细节 → 全图呈现。原照片在各幕完整保留，不默认裁剪。三种原创 FFmpeg 版式 title / editorial / hero 进入渲染适配器，而非仅手工剪一个对工具不可复现的样片。

细节幕修订：第三幕明确设置 crop=[0.43,0.38,0.28,0.28]，展示原照片中地球的局部放大，并标注 DETAIL OF ORIGINAL PHOTO。其他照片幕保留完整原图。crop 是分镜中可见的显式参数，不默认裁剪，也不生成不存在的画面；有人的照片须先人工确认裁切范围不会误伤主体。

节奏：4秒日期建立；6秒拍摄与照片；6秒观察细节；6秒全图及片名。文字分层淡入，照片运动幅度3.5%，各幕短淡出。无旁白，以本地原创程序音轨营造停顿与收束；不声称专业配乐品质已验收。

授权：仅参考 Huashu Motion 的导演方法，没有复制其代码、字体或素材。照片沿用原示例 NASA/Bill Anders 来源说明。新标题与编排为本项目制作；日期及拍摄者等事实沿用现有可追溯记录。

新增字段 layout、heading、kicker 仍由宿主 Agent 从事实生成，程序检查长度与支持值；自然语言修改也可 patch 这些字段。版式当前为横屏试作，未验证所有长文本、照片比例和竖屏布局；不替代已经验收的 v0.3.0 发布包。
